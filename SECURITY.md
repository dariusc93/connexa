# Security Policy

## Supported Versions

By default, we will provide security patches for the latest release only. We can patch older version on request.

## Reporting a Vulnerability

Please do not file a public issue on GitHub, but instead please [file a private security vulnerability report](https://github.com/dariusc93/connexa/security/advisories/new)

## Discovery or Reporting with AI

Please refer to our [AI Policy](./AI_POLICY.md) before filing any reports if AI was used in the discovery.
